# Wayseeker 设计与验证约束

这份文件记录当前仍然有效的约束：视觉体系的硬规则、交互边界，以及"什么算验证过"。
它不是验收过程的记录，也不复述某次评审发现过什么。

视觉 token 的权威来源是 [DESIGN.md](DESIGN.md)（英文）与 [DESIGN.zh-CN.md](DESIGN.zh-CN.md)；
产品定位与用户见 [PRODUCT.md](PRODUCT.md) / [PRODUCT.zh-CN.md](PRODUCT.zh-CN.md)。

## 视觉体系

四种材质：宣纸（`paper`）、墨绿漆（`lacquer`）、黄铜（`brass`）、印泥红（`seal`）。
印泥红只用于划除线与印章，不做装饰性强调色。全部样式集中在 `src/app/globals.css`，
token 与组件同一个文件 —— 改动视觉体系时不需要在两个地方对齐。

字型：展示字 Archivo 压缩宽度 + Noto Serif SC（中文展示），正文 Archivo + PingFang SC，
等宽 Fragment Mono。中文字重由一份可变字体声明承担，不再按字重重复声明分片 ——
重复声明会增加渲染阻塞 CSS。中文展示字体在 hydration 后激活，首屏先呈现本机宋体。

字体变量在根元素声明。根级字号 token 读不到 `body` 上的变量，把变量留在 `body`
会让实际字体与设计不符。

## 布局与边界状态

外框不超过浏览器高度，内容在盒内滚动。页头可以钉住，但页头过高时随页面滚动，
不能遮挡操作；固定偏移要读取实际页头高度，不写死像素。

窄屏按容器可用宽度堆叠与换行，水平内边距受视区约束。320px 是最低验收入口；
文字放大到 200% / 400% 时按钮内容允许换行、内边距受限，不出现横向找按钮。

强制的文字换行不得把英文单词切断成两截（如 PRESCRIP / TION）：需要时去掉不必要的限宽，
窄屏仍允许必要重排。

## 主题与状态

主题只接受注册表自身的键。无效的已存主题名恢复为 `system`，不能让整页无法渲染。

强制颜色模式下背景、阴影、装饰会被移除，所以选中状态必须有非颜色的表达：
阶段用下划线、当前习惯用删除线、当前抽屉用系统颜色轮廓。深浅主题切换是全局跳变，
过渡动画在同一帧会被跳过，不做逐元素插值。

减少动态时保留静态状态，悬停空闲停止帧。

## 语言

英文为默认，中文随切换持久化。字符串在 `public/locales/{en,zh}/common.json`。
首次访问由服务端读取有效语言 cookie，再按 `Accept-Language` 权重选择；显式 cookie 优先。
每个 Provider 独立初始化翻译实例，避免并发请求串语言。旧版仅存 `localStorage` 的偏好
需要一次客户端迁移，此后刷新可直接输出对应语言。

禁用 JavaScript 时中文首页与法律正文可直接阅读 —— 这不表示禁用后仍支持交互。

## 导出与复制

同表面复制互斥。字体准备最多等 2 秒，超时用本地栈回退。原生复制请求一旦被浏览器接收，
页面无法保证撤销；互斥与失败反馈不改变这个边界。恢复入口必须可见并保留原生选区，
旧反馈不能污染新上下文。

## 独立区域 /puzzles

`public/puzzles/` 是与主产品无关的独立静态区，`next.config.ts` 将它 rewrite 到静态
`index.html` 并设置 `noindex, nofollow`。它不沿用主产品的设计系统，也不能用主产品的
字体、主题或组件测试推断其质量。改动这一区时单独验证。

## 验证口径

`pnpm check` 是完整门禁（biome → tsc → build → node:test），与 CI 一致。
`pnpm test:e2e` 构建生产站点后在桌面与手机视口检查共享路径、翻转面、键盘焦点与双语详情。

证据分级，不能互相顶替：

| 级别 | 能得出的结论 | 不能得出的结论 |
| --- | --- | --- |
| 实现 | 代码与文档已交付 | 没有设备验证，不算体验闭环 |
| 浏览器证据 | 指定浏览器与条件下行为已验证 | 不等于实体设备、真实输入法或辅助技术 |
| 实体设备 | 真机上的滚动、触摸、系统权限实际可行 | 不等于有真实用户研究 |
| 真人研究 | 真实参与者能完成任务 | 不能用自动评分替代 |

已知未覆盖：实体 iPhone / Android、实际 VoiceOver、真实中文输入法组合、
真实剪贴板授权与触摸选择、首次用户研究。这些缺口保持"未验证"，不写成通过。
第三方的服务质量、法律专业意见、完整离线能力不属于本产品的验证结论。

自动化可访问性扫描的 incomplete 项不是通过项，也不能据此宣称整站符合 WCAG。
