# Wayseeker 第四轮体验验收

日期：2026-11-09。范围：前三轮遗留开发、首屏性能、首次访问语言，以及最终构建的跨浏览器与辅助功能回归。主产品范围为首页、29 个工具详情、法律页和 404；独立谜题实验区的补充检查另见验收清单。

关联：[验收清单](./UX_ACCEPTANCE_CHECKLIST_2026-11-09.md)、[第三轮报告](./UX_REVIEW_2026-11-09_ROUND3.md)、[研究执行包](./USABILITY_STUDY_2026-11-09.md)。

## 首屏与语言

原实现为 Noto Serif SC 的两个字重重复生成了同一组分片声明，增加渲染阻塞 CSS。改为单份可变字体，保留设计要求的字重；Archivo 和 Fragment Mono 取消预加载，中文展示字体在 hydration 后激活，先显示本机宋体。英文和等宽字体变量改为在根元素声明，修正原先根级样式无法读取 body 字体变量的问题。Chrome 实际渲染字体检查验证 Archivo、Fragment Mono 和 Noto Serif SC，不仅检查 CSS 字符串。

首次访问语言由服务器读取有效语言 cookie，再按 Accept-Language 权重选择。每个 Provider 独立初始化翻译实例，避免并发请求串语言。切换语言同步 cookie 和旧版 localStorage；旧版仅有 localStorage 的偏好需要一次客户端迁移，此后刷新可以直接输出相应语言。禁用 JavaScript 的中文首页与法律正文也可直接阅读；这不表示禁用 JavaScript 后仍支持交互。布局读取请求头与 cookie 后，主 UI 路由按请求渲染；部署环境的响应缓存和冷启动时间尚未实测。

## 辅助功能与边界状态

最终字体落地后继续检查 320、390、768、1440px、中英双语、深浅主题、文字放大、键盘、强制颜色和存储受限条件。已修复：

| 优先级 | 问题与后果 | 最终行为 |
| --- | --- | --- |
| P1 | 无效的已存主题名会读取不存在的图标，导致 React 整页卸载 | 主题只接受注册表自身的键；无效值恢复为 system，探索仍可继续 |
| P1 | 窄屏放大文字后固定宽度、内边距和页头遮挡操作 | 按容器可用宽度堆叠、换行，水平内边距受视区约束；固定偏移读取实际页头高度，过高页头随页面滚动 |
| P2 | 强制颜色模式会移除背景、阴影和装饰，选中状态消失 | 阶段有下划线、当前习惯有删除线、当前抽屉有系统颜色轮廓 |
| P2 | 根级字形 token 读取不到 body 上的字体变量，实际字体不符合设计 | 字体变量迁至根元素，并检验实际使用的字形来源 |
| P2 | 首次中文访问和刷新会先呈现英文再切换 | 请求级服务端语言协商；显式 cookie 优先，隔离并发翻译实例 |
| P2 | 重复中文字重 CSS 和字体抢占影响首屏与方子恢复 | 合并可变字体声明，调整字体请求时机，并保留本机回退 |
| P3 | 1440px 英文方子标题受 9ch 限宽，单词被拆为 PRESCRIP / TION | 移除不必要的限宽，完整显示 WRITE A / PRESCRIPTION；窄屏仍允许必要重排 |

正常 320px 操作名称的裁切也已消除。400% 根字号压力检查进一步发现访问按钮内边距挤压，已允许按钮内容换行并限制水平内边距。根字号 400% 加 320px 视区是额外压力检查，与桌面浏览器缩放至 400% 不是同一条件。

首页 Axe 颜色对比检查有英文 39 个、中文 9 个节点为 incomplete，404 各 1 个。本轮不据此宣称整站 WCAG 合规。机械 advisory 对应材质明暗、阴影及已记录的光学字阶，未为清空提示改变品牌。

## 冷启动对照

对照与最终版本分别中英各 3 次冷缓存，共 12 个样本。Chrome 157.0.8103.39，390×844，400ms 网络延迟，上下行各 51,200 B/s，CPU 4 倍降速；使用同一共享方子地址。最终采样时未并行运行测试。本轮按脚本实际限速比较，不与第三轮 50,000/25,000 B/s 的另一组记录混算。

| 指标（中位数） | 对照 | 最终 | 改善 |
| --- | --- | --- | --- |
| 英文 FCP | 8.196 秒 | 4.620 秒 | 43.6% |
| 中文 FCP | 8.060 秒 | 4.656 秒 | 42.2% |
| 英文共享方子恢复，五项出现 | 10.276 秒 | 8.355 秒 | 18.7% |
| 中文共享方子恢复，五项出现 | 10.387 秒 | 8.391 秒 | 19.2% |

最终 FCP 范围：英文 4.592–4.676 秒，中文 4.640–4.704 秒；方子恢复分别为 8.336–8.459 秒和 8.348–8.417 秒。改善在这组样本中可重复，样本少，不提供总体置信结论。

重复字体声明对应的 CSS 从传输 67,888 / 解压 186,280 字节降至 34,730 / 96,215 字节；全部已记录 CSS 的传输合计从 78,788 降至 45,336 字节。原对照另有根字体变量作用域错误，实际显示系统字体；最终同时恢复设计字体，不能当作同字形的纯网络实验。

中间版本只合并字体声明时，首屏改善但字体竞争使方子出现约需 14 秒；最终还调整请求时序，没有仅以 FCP 改善作为结论。最终中文直接服务端输出，避免原来的先英文后中文切换。

这些是本机限速指标，FCP 仍约 4.6 秒，不代表已达到真实移动网络的优秀体验。五项出现不是 INP 或完整可交互时间。采样 LCP 为 0，未取得有效 LCP；CLS 只观测到方子出现时。真实网络、部署冷启动、最终字体稳定后的 LCP 与完整 Core Web Vitals 均未验证。

复现：先 `pnpm build` 并启动 4000 端口的本机生产服务器，再运行 `node scripts/measure-startup.mjs --runs 3 --output /tmp/wayseeker-startup.json`。原始对照、最终样本、资源时间线、浏览器日志与截图位于本地 `.impeccable/review/2026-11-09-r4/`；该目录由 Git 忽略，不代表已发布附件。
